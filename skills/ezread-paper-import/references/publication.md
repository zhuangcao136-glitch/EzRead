# 出版信息识别与按需联网补全

## 本地证据

先识别 PDF 首页和出版页眉 / 页脚。期刊 / 会议名称、作者、正式发表 DOI、发表时间、发表页码或文章编号是卡片的核心字段。年份是可靠发表时间的可接受精度；没有日、月时不补造。卷期能识别则保存，无卷期的刊物不因此阻断导入。

PDF 页数与正式发表页码不同；文献内的 1–14 不能自动写成期刊页码。PDF 创建 / 修改时间、文件名中的年份、参考文献年份、Received / Revised / Accepted 日期都不能当作发表日期。XX / XXXX 占位符算缺失。arXiv 编号、提交时间、arXiv DOI 不等于后续期刊发表 DOI / 日期。

通过 `scripts/publication.py` 保存已识别值与 PDF 来源标记。缺项必须显式保存为未知，不用 AI 猜。结构层按原文组织，外部出版元数据不得混入右侧英文原文。

作者区域按真实标题的多行位置与横向范围定位，不能以第一个 heading 充当标题；版权、许可、单位和旁栏文字不作为作者。出版页脚中的正式引用可提供文章编号与发表日期，不能把“1 of 11”等 PDF 页计数当作期刊页码。PDF Subject 中混入的年份、卷号和文章编号须从期刊名中剥离。

标题结合字体、位置、连续行距与内部 Title 的页面对应识别；先排除出版商网址、期刊页眉、引用提示、Submitted to 等首页说明。保留多行与同一行拆开的完整标题，兼容中文短标题。内部 Title 可由导出工具生成，Author 可只是文档创建者，不能据此跳过页面核对；有效且有页面作者印证的完整内部作者名单可用于弥补分页 / 换行漏识别。

首页出版来源明确写出 Conference / Symposium / Workshop 时保存为会议论文和会议全称，不能因名称含 Robotics 或 Science 就当作期刊。会议卡片使用 conference_abbr；优先保留手工简称，再提取名称中的括号简称或匹配已核对的常用会议名称，保留全称供编辑核对。未知简称留空并提示补充，不拼造缩写。旧自动提取的会议页眉可以修正显示类型，但不覆盖手工分类、不改写原文。

新导入、缺项核对、检索记录和卡片调用同一归一化规则。对已核对的会议记录，补全可将旧自动“期刊”误分类改为会议并持久保存简称；以检索前快照判断，逐字段保留手工值与并发修改。状态 complete 与当前有效字段不一致时重新列缺项，不能因为旧状态跳过核对或绕过用户拒绝联网的选择。

## 用户选择

导入完成后，只有缺核心字段时显示应用内 `<dialog>`，列出具体缺项。弹窗沿用 EzRead 的连续圆角、柔光、克制配色和留白，不使用浏览器原生 confirm。操作为“暂不搜索”和“联网补全”；关闭、Esc 与暂不搜索等价，默认焦点在暂不搜索。

告知用户仅查询标题、作者或文献编号，不上传 PDF 全文。联网补全只授权当前文献，批量导入逐篇询问；不记成永久许可。暂不搜索依旧保留文献与后续结构整理，在详情保留补全入口。打开文献库或阅读器不主动检索旧论文。

## 检索与写入

优先用已识别的正式 DOI 查询 Crossref；无 DOI 时用标题和已识别作者查询公开书目元数据。必要时读取 arXiv 原始记录中的关联正式 DOI，再查 Crossref。请求有超时和次数边界，失败由用户决定重试。

匹配须核对标题与作者，不能接受仅关键词相似的结果；多个接近候选则提示核对，不强行选第一个。保存正式出版的年份、日期、卷期、页码 / 文章编号、DOI 和可点击来源。在线发表日期与印刷日期分别保存，不把 arXiv 提交日期冒充期刊发表日期。

明显非人名的旧作者字段不参与查询或否决匹配；缺少可靠作者时只接受高度一致且无歧义的标题。可靠作者与同名记录有冲突时明确提示作者不一致。姓名比较允许重音字符差异。

补空缺的出版字段；已验证记录也可纠正自动提取的明确非人名作者、混入书目数据的期刊名，并将同一年份的粗略日期细化为完整日期，记录 corrected 与来源。有效 PDF 字段、手动修改及检索期间发生的修改优先。有其他冲突时保留已有值并提示，不能覆盖原文、源块 ID、译文、注释、合集或阅读位置。未查到、网络失败与部分成功都保留原有内容，在同一窗口给出结果和重试入口。成功后刷新论文卡片及详情。
